# SW-Crawl

This is a web project I built to experiment with styling tricks, and interactive UI concepts, drawing inpiration from the Star Wars opening crawl. 

## Project Structure

* **`index.html`** - The main body page of the website; it has the story I wrote.
* **`style.css`** - It is the CSS stylesheet that has the code for the animation
* **`JOURNAL.md`** - A journal of my progress while building the website. 
* **`background.jpg`** - The space-themed backdrop image of the website. 

# Deployment

You can visit the website from this URL: ```https://sw-crawl.vercel.app/ ```<br> 
**OR** <br> 
You can clone this repository to your local machine to view it: <br>

   git clone https://github.com/NivedhGovil/SW-Crawl.git
