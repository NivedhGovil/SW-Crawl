# SW-Crawl

This is a web project I built to experiment with frontend layout design, styling tricks, and interactive UI concepts. 

## Project Structure

* **`index.html`** - The primary HTML document that sets up the main DOM structure and page content.
* **`style.css`** - Custom CSS stylesheets responsible for the overall look, feel, and responsiveness of the site.
* **`JOURNAL.md`** - A personal dev log where I track my progress, document random thoughts, and note down roadblocks as I build.
* **`background.jpg`** - The backdrop asset used to establish the visual style and atmosphere.
